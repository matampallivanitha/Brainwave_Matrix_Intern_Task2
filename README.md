# Hospital Management System – Java Project

This is a console-based **Hospital Management System** developed as part of a Java programming internship. The system is designed to manage the key functions of a healthcare facility such as **patient registration, appointment scheduling, electronic health records (EHR), billing, inventory**, and **staff/doctor management**.

## Features

### Doctor Registration
- Add, update, view, and delete doctor details

### Patient Registration
- Register new patients
- Update patient details
- View patient records

### Appointment Scheduling
- Book, cancel, reschedule appointments
- View appointment history by patient ID

### Electronic Health Records (EHR)
- Add, update, and view medical records
- Generate medical reports
- View full medical history

### Billing & Invoicing
- Add billing entries
- Create and view invoices
- Process payments
- View payment history

### Inventory Management
- Add medical supplies
- View inventory stock

### Staff Management
- Add, edit, and view hospital staff details


## Technologies Used

- **Java** (JDK 8 or higher)
- **MySQL** – for data persistence
- **JDBC** – to interact with the database
- **Command Line Interface** – for user interaction
